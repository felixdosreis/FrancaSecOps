# França SecOps

França SecOps é uma página de apresentação de uma proposta de serviços gerenciados de segurança da informação. O projeto comunica como um Centro de Operações de Segurança (SOC) pode apoiar empresas no monitoramento e na triagem de alertas, na resposta a incidentes e na auditoria de bancos de dados, com atenção à proteção de dados e à LGPD.

## O que o projeto apresenta

- Monitoramento conceitual de VPN, perímetro DMZ, estações de trabalho e relatos de phishing.
- Uma demonstração visual de alertas classificados por gravidade e de etapas de triagem.
- Propostas de serviços SOC e auditoria de banco de dados.
- Princípios de controle de acesso, resposta a incidentes e rastreabilidade.

## Estado atual

Este repositório contém uma página estática feita em HTML, CSS e JavaScript, em [Painel final Banco de dados index.html](<Painel final Banco de dados index.html>). A tela de alertas é uma simulação visual: o projeto ainda não coleta eventos reais, conecta-se a um banco PostgreSQL ou executa operações de SOC.

O formulário de contato também é demonstrativo. Ele valida os campos no navegador, mas não envia nem armazena solicitações. Para uso operacional, será necessário implementar e conectar um backend aos serviços e dados reais.
